== Cross-repo wiring

KnotTheory.jl supplies the *mathematics*; Skein.jl is the *engine* that computes
and persists invariants (optionally using this library via `KnotTheoryExt`);
quandledb is the *equivalence/identity face*. The load-bearing shared invariant
across the stack is *equivalence-integrity* (the `a = a` idem core) — KnotTheory.jl
contributes the underlying invariant mathematics that makes a computed equivalence
meaningful.

Sibling repos' key concerns (keep in sync as crossover resolves): *Skein.jl* —
computational engine + persistence (consumes this library); *quandledb* —
equivalence / identity face; *tangle* — TangleIR + type-safe core; *krl* —
resolution DSL surface; *echo-types* — structured-loss theory + the identity-fabric
framing (Conway·Fichte / Bruner / Ricoeur). See `../../AFFIRMATION.adoc`.
