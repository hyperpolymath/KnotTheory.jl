= KnotTheory.jl — Source Directory
:toc:

== Overview

This directory contains the entire Julia implementation of the `KnotTheory`
module. The module is a single-file monolith (`KnotTheory.jl`) following
Julia's idiomatic module layout: one top-level file that `include`s
auxiliary files and re-exports everything the public API needs.

== Files

[cols="1,3"]
|===
| File | Purpose

| `KnotTheory.jl`
| Main module file (~2 400 LOC). Declares the `KnotTheory` module, all
  exports, and contains the full implementation of types, invariants,
  diagram transformations, and the knot table. Includes
  `backends/abstract.jl` for coprocessor dispatch.

| `backends/`
| Subdirectory for backend-dispatch glue. See `backends/README.adoc`.
|===

== Architecture

The module is laid out in sections, in read-order dependency order:

[cols="1,3"]
|===
| Section | Content

| Types
| `EdgeOrientation`, `Crossing`, `PlanarDiagram`, `DTCode`, `GaussCode`,
  `Knot`, `Link`. These are the data model; everything else is functions
  over them.

| Constructors / knot table
| `unknot`, `trefoil`, `figure_eight`, `cinquefoil`, `knot_table`,
  `lookup_knot`. The table covers all prime knots up to 9 crossings.

| Diagram interconversions
| `to_pd`, `to_dt`, `from_dt`, `to_gauss`, `from_gauss`, `pdcode`,
  `dtcode`, `to_dowker`. Conversions between the three standard
  combinatorial representations.

| Simplification
| `simplify_pd`, `r1_simplify`, `r2_simplify`, `r3_simplify`. Local
  Reidemeister-move reductions on PD codes.

| Seifert surface
| `seifert_circles`, `seifert_circles_with_map`, `seifert_matrix`,
  `braid_index_estimate`. Seifert algorithm over PD codes.

| Polynomial invariants
| `alexander_polynomial`, `jones_polynomial`, `conway_polynomial`,
  `homfly_polynomial`. Invariant computation dispatched through
  `backend_*` hooks (pure Julia by default; coprocessor-accelerated
  when an `AcceleratorGate` backend is active).

| Numerical / matrix invariants
| `signature`, `determinant`. Computed from the Seifert matrix.

| Braid interconversion
| `from_braid_word`, `to_braid_word`. Uses the Seifert-circle approach
  to produce a braid representative.

| Serialisation
| `write_knot_json`, `read_knot_json`. Round-trips `Knot` objects
  through JSON3, preserving all arc labels and crossing signs.

| Visualisation
| `to_graph`, `to_polynomial`, `plot_pd`. Thin wrappers to Graphs.jl
  (adjacency graph of the PD diagram) and CairoMakie (basic PD plot).
  CairoMakie is an optional dependency; `plot_pd` errors gracefully if
  it is not loaded.
|===

== Adding new code

* **New invariants**: add a `backend_*` dispatch hook in
  `backends/abstract.jl` alongside the Julia fallback; put the
  implementation inline here. That pattern lets a future
  coprocessor backend override the hot path without touching this file.

* **New types or representations**: add to the Types section; update
  `to_graph` and the serialisation functions accordingly.

* **New knot table entries**: edit the `knot_table` dictionary near the
  bottom of the file.

Do NOT edit files in `Skein.jl/` or `KRLAdapter.jl/` from here —
those are separate packages. Integration goes in `KRLAdapter.jl`.
