= KnotTheory.jl — Backend Abstraction Layer
:toc:

== Purpose

This directory contains the coprocessor-dispatch glue that decouples
the core mathematical algorithms from the execution hardware. All
compute-intensive paths in `KnotTheory.jl` call a `backend_*` hook
defined here. The Julia fallback (CPU, no acceleration) is always
present; alternative backends (GPU, FPGA, ASICs) can override the hot
path by loading an `AcceleratorGate` backend at runtime.

== Files

[cols="1,3"]
|===
| File | Purpose

| `abstract.jl`
| Defines the five dispatch hooks and their Julia fallbacks, then
  uses `AcceleratorGate.generate_self_healing_hooks` to wire coprocessor
  overrides with automatic fall-through to Julia on failure or absence.
|===

== Dispatch hooks

[cols="1,3"]
|===
| Hook | Used for

| `backend_polynomial_eval`
| Evaluating polynomial invariants at a point (Jones/HOMFLY evaluation loop).

| `backend_jones_invariant`
| Full Jones polynomial computation via Kauffman bracket.

| `backend_alexander_polynomial`
| Alexander polynomial from the Seifert matrix.

| `backend_matrix_det`
| Determinant computation for the Seifert matrix (also used by `signature`).

| `backend_braid_reduce`
| Braid word reduction (handles large braid words that are slow in Julia).
|===

== Adding a new backend

. Add a method dispatching on your concrete `AcceleratorGate` backend type:
+
[source,julia]
----
using AcceleratorGate: MyCustomBackend
backend_jones_invariant(::MyCustomBackend, pd::PlanarDiagram) = ...
----
. The `generate_self_healing_hooks` call in `abstract.jl` will route any
  coprocessor invocation to your method, and fall back to the Julia
  implementation if your method throws or is unavailable.

No changes to `abstract.jl` itself are needed for new backends.

== AcceleratorGate dependency

`AcceleratorGate` is the shared coprocessor-dispatch infrastructure used
across the hyperpolymath KRL stack. It provides the `JuliaBackend`,
`CoprocessorBackend` hierarchy and `generate_self_healing_hooks`.
Source: `developer-ecosystem/` monorepo.
